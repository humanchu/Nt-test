Start

Wähle einen Lerntag. Jede Runde dauert etwa 10–20 Minuten. Falsche Antworten werden am Ende nochmal wiederholt.

Eltern-Spickzettel

Wirbeltiere: Fische = Schuppen/Kiemen/Eier/wechselwarm; Amphibien = feuchte Haut/Haut+Lunge/Eier/wechselwarm; Reptilien = trockene Schuppen/Lunge/Eier/wechselwarm; Vögel = Federn/Lunge/Eier/gleichwarm; Säugetiere = Fell/Lunge/lebendgebärend/gleichwarm.

Evolution: Variation → Selektion → Fortpflanzung/Vererbung → Mutation und Wiederholung.

Blütenpflanze: Wurzel, Sprossachse, Blatt, Blüte. Blüte: Kelchblatt, Kronblatt, Staubblatt, Stempel/Fruchtknoten.

Bestäubung/Befruchtung: Pollen vom Staubbeutel auf die Narbe → Pollenschlauch wächst → männliche Zelle trifft Eizelle → Samen/Frucht entstehen.
